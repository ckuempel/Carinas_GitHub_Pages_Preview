# Particle Screensaver

An interactive, animated screensaver application built with HTML5 Canvas, CSS, and JavaScript. The screensaver features colorful bouncing particles, dynamic connections, and mouse/touch interactivity.

## Features

- **Animated Particles**: Colorful particles bounce around the screen with realistic physics
- **Dynamic Connections**: Particles connect with lines when they're near each other
- **Color Cycling**: Particles smoothly cycle through the color spectrum
- **Interactive**: Create particles by moving your mouse or touching the screen
- **Fullscreen Mode**: Enter fullscreen for an immersive experience
- **Performance Monitoring**: Real-time FPS and particle count display
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **Dark Theme**: Beautiful dark gradient background with glowing effects

## Controls

- **Pause/Resume**: Pause and resume the animation
- **Reset**: Clear all particles and restart with 100 particles
- **Fullscreen**: Toggle fullscreen mode for better immersion
- **Mouse Move**: Move your mouse to create trails of particles
- **Touch**: On touch devices, swipe to create particle trails

## Technical Details

- Built with vanilla JavaScript (no dependencies)
- Uses HTML5 Canvas for rendering
- Implements particle physics simulation
- Color effects using HSL color space
- Optimized for smooth animation with requestAnimationFrame
- Responsive to window resizing

## How to Use

1. Open `index.html` in your web browser
2. Watch the particles animate across the screen
3. Move your mouse around to interact
4. Use the control buttons to pause, reset, or go fullscreen

## Browser Compatibility

Works on all modern browsers that support:
- HTML5 Canvas
- ES6 JavaScript
- requestAnimationFrame
- CSS Backdrop Filters

Tested on:
- Chrome/Chromium
- Firefox
- Safari
- Edge
